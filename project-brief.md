# My project brief

## The Question
Which part of Benin city are the farthest from a formal waste collection point?
The answer to the query above will help policymakers and decisionmakers in the state government ensure environmental stewardship.

## The Data:

- OSM formal waste collection points
- Road network
- Settlement extent
- Population
- Administrative boundary

## The Sources of data 
1. OSM formal waste collection points; https://overpass-turbo.eu/# 
2. Road network; https://overpass-turbo.eu/# 
3. Settlement extent; https://data.grid3.org/ 
4. Population; https://www.worldpop.org/ 
5. Administrative boundary; https://data.grid3.org/

## Description
Over the 12 months of the bootcamp, I’ll be building a decision support platform for assessing accessibility to waste collection facilities in Benin city.
